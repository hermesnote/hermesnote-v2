## 實作

| 段 | 內容 | 檔案 |
|---|---|---|
| M2 暖機 | 記憶類型（none／finite／recursive／composite／cumulative／unknown）；有限型＝lookback、遞迴型＝lookback＋ceil(ln ε／ln(1−α))（ε 預設 0.01）、複合／未知必須研究者設定 `warmup.bars`、只能加長；實測建議 API | `registry/warmup.py`、`routers/model_experiments.py`（`/warmup/suggest`） |
| M2 轉換 | diff、pct_return、log_return、rolling_sum（x_t−x_{t−N}）、fixed_anchor、legacy_cumulative（提示）；累積型必選 | `registry/transforms.py` |
| M2 往前載入 | 依暖機＋窗格＋上游需求算每個時間框架要往期間前載入幾根；讀取報告記錄 requested／loaded／shortfall | `v2_inputs.history_requirements`、`services/quotes.py`（`lookback_bars`、`load_from`、`with_session`） |
| M2 共同樣本框架 | 決策時間框架＝Label 時間框架；Phase 1 random（實驗層切分種子）、Phase 2 chronological（`boundary` 排除）、Phase 3 holdout（`label_unmatured`）；雜湊＝定義＋時間點＋狀態；上游框架由下游推導 | `training/frame.py` |
| M2 原因代碼 | insufficient_history、warmup_not_ready、stale_branch、upstream_unavailable、upstream_purged、label_*、boundary…；排除比例 > 5%（可調）提示 | `v2_inputs.assemble`、`engine_v2` |
| M3 Phase 3 | best、last 都推論、都評估（同一套評估函式與 evaluations 格式，`dataset.split=holdout`）；尾端未成熟保存不評估；基準用產物的 `train_stats`；舊產物也支援（推論沿用舊路徑） | `holdout_eval.py`、`v2_records.py`、`worker_v2.py` |
| M3 紀錄 | 逐筆結果（val／holdout，best＋last；串接時另存下游訓練點的上游來源）、評估紀錄、holdout 使用紀錄（推論、評估、比較各一筆）、階段門檻（只提示，409＋理由／確認人放行並記錄）、模型種子一對一銜接 | `experiment_store.py`、`routers/model_experiments.py` |
| M4 對齊 | 以 bar_start_ts 識別、bar_end_ts＋延遲判定可用；as-of、子 K 棒彙總；`allow_previous_session`（預設 true）、`max_sessions_back`（預設 1）、`max_age_sec`（預設不限）；延遲依資料表×時間框架、預設 0 秒 assumed；舊格式跨時間框架仍拒絕 | `training/alignment.py` |
| M5 串接 | forward_chaining（預設 K=5）、purged_kfold、blending、in_sample（提示）；上游只用框架 train 點、折內再切驗證段；自動清除（下游跨度＋上游跨度，99 百分位）＋逐筆檢查；折次清單；獨立核對（5 條規則，API／CLI／CSV） | `cascade.py`、`cascade_audit.py` |
| M6 多分支 | 分支（時間框架、window、encoder：lstm／flatten／last_value、各自 global_minmax）；打包成 (n, W_max, F_total)；LSTM 多分支網路、XGBoost 只取有效欄位；單一分支沿用舊網路 | `v2_inputs.py`、`registry/lstm.py`、`registry/xgboost_model.py` |
| M7 前端 | 後台「模型實驗」：建立實驗、對齊規則與門檻編輯（含修改紀錄）、組別、框架版本、Phase 1／2／3 執行與門檻放行、任務明細（排除原因、各分支沿用前一時段筆數與距決策時刻、暖機、串接、holdout 統計、評估表、串接核對、逐筆結果）、配對比較、holdout 使用紀錄；訓練頁資料紀錄加 v2 框架／排除／分支／暖機與往前載入 | `admin/sections/ModelExperiments.tsx`、`ModelTrainingPage.tsx` |
