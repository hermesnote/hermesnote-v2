# 2026-08-18

## 討論內容

**網站定位修正**
- 不是求職作品集，是研究敘事型個人網站；求職只是附帶功能
- 訪客只看展示層，不開放外部操作；記帳例外——記帳需要開放家庭成員登入操作（跟研究/量化系統「僅自己登入」不同，記到 [[project_hermesnote_v2]]）
- 實驗訓練/回測改由 Hermes Agent 打 API 送出，網站本身不做操作台

**版型方向**
- 不要 navbar，走單頁式滾動敘事，記帳等需要驗證的操作移到後台，不在滾動敘事裡
- 參考 Medusa（白底、留白、圖表化）+ Chronicle（滾動漸次揭露、左右交錯區塊）+ Horizon/Hypothesis Memory（密集監控面板美學，僅當靈感參考，非literal 目標）
- Logo 由 Hermes 自建（`data/icons/brand/`），五根 K 棒組成字母 H，色票 Ink #17161A / Break Red #BF3A2B / Paper #F6F4F0

**技術決策**
- 前端 React + TypeScript + Vite，版本鎖定 vite ^6.3.1（vite 8 的 rolldown 原生綁定在此機器上會裝失敗，改用舊站已驗證版本）
- 後端 FastAPI，分層改善（router/service/repository），本階段尚未動工
- 圖表函式庫方向：TradingView 有免費嵌入 widget 可用；MultiChart 無法嵌入；TA-Lib／回測套件是後端算數據，不是顯示層——這件事還沒真的選定套件，只是釐清了角色分工
