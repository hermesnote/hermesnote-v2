# Hermesnote 品牌檔案

## 色票
- Ink #17161A — A/B/C 棒、文字
- Break Red #BF3A2B — D/E 棒、品牌色（淺底用）
- Break Red Dark #E2624F — 僅深底使用
- Paper #F6F4F0 — 背景、反白

## 標誌敘事
五根 K 棒組成字母 H：A 長黑 K（落底）→ B 實體、C 十字星、D 錘子（整理）→ E 長紅 K（突破）。

## 字標
Archivo：Hermes 700 / note 500（色階退一階，Ink 70%），字距 -0.035em。無副標。

## 尺寸降階
- 40px 以上：mark-full（含影線）
- 20–40px：mark-simplified（保留紅色 D 的下影線）
- 20px 以下：mark-tiny（直角四棒）
- 最小可用 12px

## 留白
四邊淨空 = A 棒寬度。禁止非等比縮放、旋轉、換色、加大棒距。

## svg/
向量原稿，可無限放大。
lockup-horizontal*.svg 的文字是 text 元素，開啟的電腦若沒有安裝 Archivo 會換成替代字型；
需要保險時請改用 png/lockup-*.png。

## png/
- favicon-16/32/48/180/512：深底方形。16/32 用直角四棒、48 用簡化版、180/512 用完整版
- avatar-circle-400/800、avatar-square-400/800：社群頭像（保留細影線、加大留白）
- mark-*-transparent：透明底符號，墨色版與反白版
- mark-512-paper / mark-512-dark：帶底色版本
- lockup-paper / lockup-dark：符號＋字標，字型已點陣化，最保險
